# Factory v3 Strategy

## Version
v0.1

## Change Log
- v0.1 (2026-05-18): Initial strategy note for Factory v3 research.

## Status
Strategic research only. This document does not change Factory v2 behavior.

## Strategic Thesis
Factory v2 is a planning and governance process for bounded agentic development. Factory v3 should explore mission-governed autonomous execution for coding agents, but only after the ideas have been tested through v2 packs, shadow artifacts, advisory validators, pilot runs, and explicit promotion criteria.

## Operating Principle
Use Factory v2 to build Factory v3.

This means:
- v3 work starts as planning-only Factory runs.
- v3 concepts are documented before they are schematized.
- v3 schemas remain shadow candidates before enforcement.
- v3 validators run in advisory mode before they can block.
- v3 pilot profiles collect eval evidence before release.
- v3 release requires an explicit human promotion decision.

## Staged Path
1. Keep the v2 core intact.
2. Add v3 strategy and boundary notes.
3. Add v3 concept and shadow schema candidates.
4. Add advisory validators that do not affect v2 required gates.
5. Run v3 pilot profiles against real or historical Factory work.
6. Capture evals and stress-test results.
7. Promote selected v3 contracts only after evidence and release approval.
8. Add runtime integration only through project adapters, not Factory Core.

## Evaluation Themes
V3 research should capture:
- drift detected before execution
- false positives from advisory checks
- false negatives missed by advisory checks
- overhead added to normal v2 runs
- clarity for public starter-kit users
- AEGIS-boundary compliance
- evidence quality for promotion decisions

## Release Bar
A v3 release should not be declared until:
- v2 remains usable and documented as current until the release decision
- research artifacts are tested in shadow or advisory mode
- pilot evidence shows useful signal
- AEGIS compatibility does not imply dependency
- runtime-kernel behavior remains out of Factory
- a human release decision promotes specific artifacts
